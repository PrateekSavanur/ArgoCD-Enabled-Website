# Public Assets

Place the following files here:

- `og-image.png` (1200×630) — Open Graph image for social sharing
- `favicon.ico` — site favicon
- `apple-touch-icon.png` — iOS home screen icon

## Generating og-image.png

You can generate one quickly using a tool like:
- https://og-playground.vercel.app/
- Figma / Canva with the terminal theme colors:
  - Background: `#0a0a0a`
  - Primary text: `#00ff41`
  - Accent: `#ffb000`
  - Font: JetBrains Mono
